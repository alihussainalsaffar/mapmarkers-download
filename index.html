Map Markers

Install Map Markers

Flutter project by Ali Alsaffar

Android

Save your favorite places on a map, search for addresses, and get directions. The app asks for your location only when you tap the location or directions button.

Download for Android (52 MB)
  1. Open the downloaded file.
  2. If asked, allow installing from this source.
  3. Tap Install, then Open.

iPhone

iPhone apps can't be installed from a web page, so this opens the same app in Safari. Allow location when Safari asks, so the location and directions buttons work.

Open Map Markers in the browser
  1. Tap Share in Safari.
  2. Tap Add to Home Screen to keep it as an icon.
Source code is in the private Gitea repo aalsaffar/map-markers. Map data © OpenStreetMap contributors.
